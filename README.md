# My Learning Site

A learning project to practice and implement HTML & CSS fundamentals. Includes multiple pages with different layouts, styling techniques, and responsive design patterns.

Developed by Rifqi Mulyawan — [rifqimulyawan.com](https://rifqimulyawan.com)

## Features

- **Multi-page Layout** — Home, About, Gallery, Events, and Contact pages
- **Responsive Design** — Mobile-friendly CSS layouts
- **Contact Form** — HTML form with validation
- **Gallery** — Image gallery with CSS grid/flexbox
- **Asset Management** — Organized static assets (images, CSS)

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Installation

No build step required — static HTML files.

```bash
git clone https://github.com/rifqimulyawan/my-learning-site.git
cd my-learning-site
```

Open `index.html` in your browser, or serve with a static file server:

```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## Project Structure

```
my-learning-site/
├── index.html       # Home page
├── about.html       # About page
├── gallery.html     # Image gallery
├── event.html       # Events page
├── contact.html     # Contact form
└── assets/          # Images and stylesheets
```
